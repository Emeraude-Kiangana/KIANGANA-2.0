# KIANGANA 2.0 — Gate Zero

KIANGANA 2.0 est un système opératoire humain–IA réunissant orchestration, gouvernance de projets et intelligence stratégique.

## Principe directeur

Une intention ne devient jamais automatiquement une action. Toute mission suit la chaîne :

`Objectif → Contrat → Plan → Exécution → Test → Preuve → Validation → Clôture`

## Démarrage

```bash
python3 scripts/validate_gate_zero.py
python3 -m unittest discover -s tests -v
```

## Structure

- `governance/` : permissions, décisions et registre des capacités.
- `templates/` : contrats de mission, preuves et rapports de clôture.
- `schemas/` : validation mécanique des contrats.
- `docs/` : architecture et règles d’exploitation.
- `scripts/` et `tests/` : contrôles Gate Zero reproductibles.

## Projets pilotes

1. eCDF — recherche et prototype technologique ; aucune prétention institutionnelle.
2. AGRICHAIN DAO — infrastructure agroécologique et RWA, en phase de conception.
3. Open Technologies Portfolio — preuves publiques des compétences et réalisations.

## Définition de “Gate Zero validé”

- les fichiers obligatoires existent ;
- les niveaux P0–P5 sont définis ;
- chaque plugin possède propriétaire, finalité, données et niveau maximal ;
- les missions exigent tests, preuves et validation ;
- les secrets sont exclus du dépôt ;
- les contrôles automatisés passent.
