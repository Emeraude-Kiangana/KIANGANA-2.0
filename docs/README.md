# KIANGANA 2.0 Documentation

## Project role

KIANGANA 2.0 is a human–AI operating system for governed project execution, evidence capture and strategic orchestration.

## Documentation map

- [Root README](../README.md) — Gate Zero framing and operating chain.
- [Project Status](PROJECT-STATUS.md) — current factual verification state.
- [GitHub Documentation Standard v1.0](GITHUB-DOCUMENTATION-STANDARD-v1.0.md) — common repository documentation rules.
- `governance/` — permissions and operating decisions.
- `missions/` — mission contracts.
- `reports/` — completion and validation reports.
- `evidence/` — proof records.
- `schemas/` — machine-verifiable contracts.
- `dashboard/` — command-center views.
- `research/` — research records.

## Core rule

Intent → Contract → Plan → Execution → Test → Evidence → Validation → Closure.

No subsystem status should be generalized to the whole system unless the corresponding global gate is also green.
