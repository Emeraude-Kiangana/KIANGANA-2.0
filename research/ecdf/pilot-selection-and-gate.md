# eCDF — Sélection du pilote et Gate terrain

## Grille de sélection

Noter chaque critère de 0 à 2 : 0 absent, 1 partiel, 2 confirmé.

| Critère | Score |
|---|---:|
| Problème de preuve ou de rapprochement observé | /2 |
| Volume ou fréquence suffisant pour un test | /2 |
| Producteurs, coopérative et payeur accessibles | /2 |
| Responsable local autorisé et disponible | /2 |
| Consentement et protection des données possibles | /2 |
| Processus actuel documentable | /2 |
| Test sans argent réel possible | /2 |
| Connectivité faible prise en compte | /2 |
| Aucun conflit réglementaire identifié à ce stade | /2 |
| Indicateurs mesurables avant/après | /2 |
| **Total** | **/20** |

## Seuils

- **GO : 16–20**, aucun critère critique à zéro.
- **PIVOT : 11–15**, ou besoin confirmé mais acteur/processus à modifier.
- **NO-GO : 0–10**, consentement impossible, absence de besoin, risque majeur ou terrain non autorisé.

Critères critiques : autorisation locale, consentement/protection des données, test sans fonds réels et absence de conflit manifeste.

## Indicateurs V0

1. délai médian entre paiement annoncé et confirmation ;
2. part des transactions avec preuve retrouvable ;
3. taux de rapprochement livraison-paiement ;
4. nombre de litiges par période ;
5. délai de résolution d'un litige ;
6. coût estimé de vérification par transaction ;
7. taux d'échec ou de paiement non confirmé.

## Décision humaine

Le score informe la décision; il ne la prend pas. Emeraude Kiangana valide et signe l'une des décisions : GO, PIVOT ou NO-GO. Même avec un score GO, aucun simulateur n'utilise de fonds réels ni de données identifiantes.
